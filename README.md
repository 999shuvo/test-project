# test-project

A Node.js project that loads environment variables with [dotenv](https://github.com/motdotla/dotenv).

## Requirements

- Node.js 18 or later

## Setup

```bash
npm install
```

Create a `.env` file in the project root for local configuration. Do not commit it.
